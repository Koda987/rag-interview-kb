# AI 面试八股知识引擎 🎤

帮你把面试八股真正**背下来**的工具：AI 面试官主动提问，你先作答、再用碎片拼图还原标准答案、或把挖空的术语填回去——每一题都经过一次主动回忆，AI 逐题点评并给出场次报告。

内置 Transformer 注意力 / RAG 检索 / 大模型基础 / Prompt 与 Agent / 工程实践 5 篇 AI 方向八股语料，开箱即练；也可以粘贴任意自己的资料，AI 自动出题入库。

## 🎯 核心玩法 · 模拟面试

选题（主题 × 题数 × 模式）→ AI 面试官流式开场白 → 逐题作答 → AI 逐题点评 → 场次报告。

### 三种学习模式

| 模式 | 玩法 | 适合 |
|---|---|---|
| 练习模式 | 先自由作答，再用碎片拼图还原标准答案 | 第一遍系统学 |
| 速记模式 | 跳过作答，直接拼图 | 快速过题巩固 |
| 填空模式 | 答案中的英文术语自动挖空，从词池点词填入 | 抠术语细节 |

### 设计亮点

- **干扰句拼图**：碎片池混入本场其他题目的句子——按顺序硬背无效，必须真的理解答案才能拼对
- **AI 面试官全程陪练**：开场白、逐题点评、场次总结全部流式输出，像一场真面试
- **错题本**：拼错/填错的题自动进错题本（浏览器本地持久化），可一键「只练错题」
- **端点防作弊**：题目与标准答案一律服务端自查，请求只传题号与作答产物，改请求也偷不到答案

## 📥 导入我的八股

- **手动粘贴**：按 `Q:` / `A:` 格式粘贴文本，校验后写入题库，热重载即时生效、无需重启
- **AI 出题**：粘贴任意资料（50–8000 字），LLM 流式生成问答对，逐条编辑确认后入库——讲义、博客、面经都能变题库

## 🤖 配套能力

- **智能对话**：RAG 语义检索知识库 Top-5 相关片段，流式生成回答，支持多轮对话与历史会话管理
- **知识库管理**：三步向导（数据源 → 分段与清洗 → 入库），分段参数滑杆调节、实时预览，MD5 去重，支持按文档删除

## 🚀 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置密钥（SiliconFlow 平台申请）
#    Windows（用户级，需重开终端生效）: setx OPENAI_API_KEY "你的密钥"
#    Linux/Mac:                        export OPENAI_API_KEY="你的密钥"

# 3. 初始化数据库
python manage.py migrate

# 4. 启动（默认端口 8001）
python run.py
```

## 🛠️ 技术栈

| 层 | 技术 |
|---|---|
| 编排 | LangChain（LCEL） |
| 向量库 | ChromaDB（本地持久化） |
| 模型 | BAAI/bge-m3（Embedding）+ DeepSeek（Chat），经 SiliconFlow API 调用 |
| 后端 | FastAPI + Django 组合 ASGI（`/api` 走 FastAPI，`/admin` 走 Django） |
| 前端 | 原生 HTML/CSS/JS，无框架无构建 |

## 📁 目录结构

```
├── run.py                # 启动脚本（密钥预检 + uvicorn）
├── config_data.py        # 全局配置（路径 / chunk 参数 / 模型 / 检索 top_k）
├── apps/
│   ├── api/              # FastAPI 路由与 Schema
│   │   └── routers/      #   qa（问答）/ knowledge（知识库）/ interview（面试官）
│   └── core/services/    # 服务层：RAG / 向量库 / 题库 / 面试官 / 切块
├── static/               # 前端四页（落地 / 对话 / 知识库 / 模拟面试）
├── data/                 # 八股题库语料（Q:/A: 格式 .txt，追加即新增主题）
├── experiments/          # chunk 参数实验脚本与报告
└── rag_project/          # Django + FastAPI 组合 ASGI 配置
```

## 📝 说明

- 题库就是 `data/*.txt` 源文件（`Q:` / `A:` 格式），加一篇就多一个可选题库主题
- `chroma_db/`、`chat_history/`、`md5.text` 等运行时数据不入库（见 .gitignore），克隆后按「快速开始」重建
- 密钥仅通过环境变量 `OPENAI_API_KEY` 提供，不进代码与仓库
